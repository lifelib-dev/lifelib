# economic_curves (placeholder)

**This library no longer contains any code or notebooks. It is kept only as a
placeholder so that links to it do not break.**

The *economic_curves* library was introduced in lifelib v0.8.0 as a mirror of
[insurance_python](https://github.com/open-source-modelling/insurance_python),
a repository maintained by
[Open-Source Modelling](https://github.com/open-source-modelling)
(formerly *Actuarial Algorithms*).

Open-Source Modelling has kept developing the original repositories, while the
copy in lifelib was left untouched and became outdated. Rather than shipping and
rendering stale copies, lifelib now points to the upstream repositories
directly, so that you always get the latest version of the algorithms and
notebooks.

## Where the contents went

| What you were looking for | Where it is now |
| --- | --- |
| Python algorithms (Smith-Wilson, Nelson-Siegel-Svansson, stationary bootstrap, Black-Scholes, correlated Brownian motion, bisection alpha, ...) | [open-source-modelling/insurance_python](https://github.com/open-source-modelling/insurance_python) |
| Jupyter notebooks (EIOPA RFR recalculation, Metropolis-Hastings, Hull-White checks, ...) | [open-source-modelling/insurance_jupyter](https://github.com/open-source-modelling/insurance_jupyter) |

All the repositories above are released under the MIT License by
Open-Source Modelling.

See the
[economic_curves page](https://lifelib.io/libraries/economic_curves/index.html)
in the lifelib documentation for an introduction to Open-Source Modelling and
links to their other projects.

## Looking for modelx-based economic models in lifelib?

* The [economic](https://lifelib.io/libraries/economic/index.html) library
  contains a Hull-White model built with modelx.
* The [smithwilson](https://lifelib.io/projects/smithwilson.html) project
  contains a primitive Smith-Wilson implementation built with modelx.
