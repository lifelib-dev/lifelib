# Sources

actuarial references) are carried **verbatim** from `_research/per-assurance.md` and are
frozen — never renumber. Only sources actually cited in `product-spec.md` or
`technical-notes.md` are listed. **No id is omitted:** all ten primary sources S1–S10 and
all twenty-four references R1–R24 recorded in the research file are cited by the two
documents in this directory, so the lists below are complete and carry no gaps. No new
source was fetched at drafting; every access date is **2026-08-26**, matching the research
file's header statement.
